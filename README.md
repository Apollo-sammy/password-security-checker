# Password Security Checker

## Overview
Password Security Checker is a Python-based application
that evaluates password strength using basic security
requirements. It identifies missing criteria and provides
a strength rating to encourage better password practices.

## Features
- Checks minimum password length of 8 characters.
- Detects uppercase and lowercase letters.
- Verifies the presence of numbers.
- Checks for special characters.
- Identifies missing security requirements.
- Classifies passwords as Weak, Medium, or Strong.

## Technologies Used
- Python 3
- String manipulation
- Conditional statements
- Functions and loops

## Installation and Usage

1. Clone or download this repository.
2. Install Python 3 if it is not already installed.
3. Open a terminal in the project directory.
4. Run the application:

   python password_checker.py

5. Enter a password and review the results.

## How It Works
The application evaluates the password against five
security criteria. It displays unmet requirements and
assigns a strength rating based on the results.

## Security Notice
This project is intended for educational purposes.
Its rating uses basic rules and does not guarantee
password security. Use unique passwords for different
accounts and consider a reputable password manager.
